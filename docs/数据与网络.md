# 数据、网络与署名

旅行记录是仓库中的普通Markdown，照片是仓库附件。插件扫描所配置的旅行目录，不上传笔记、回忆、照片或设置。地球、城市搜索和记录展示无需账户或API密钥。

| 资源 | 使用与联网范围 | 来源与限制 |
| --- | --- | --- |
| 自然地表、云层、粗高程 | 随包提供，优先本地读取；启用联网底图更新时后台检查 | NASA／GEBCO历史合成，不是实时天气或精密导航；见[来源](../assets/realistic/SOURCES.md) |
| 国界、名称、水系 | 随包提供，运行期不下载制图脚本 | Natural Earth Public Domain，示意口径；见[溯源](../assets/atlas/provenance.json) |
| 离线城市目录 | 随包提供 | GeoNames，保留第三方说明中的来源与署名；地名点不等同于全球市域 |
| 精细高程 | 按浏览范围获取，缓存后可离线复用；与联网底图更新共用开关 | Terrain Tiles／Terrarium，各地区来源见[地形署名](../assets/terrain/ATTRIBUTION.md) |
| 城市卫星影像 | 按视野获取，独立联网开关；仅已缓存区域离线可用 | EOX Sentinel-2 cloudless 2024，CC BY-NC-SA 4.0，仅非商业使用 |

联网服务可看到请求的IP和瓦片／资源路径；瓦片请求范围反映当前浏览区域。关闭相应联网选项可停止插件相应请求，未下载的细节会使用低精度后备。外部服务可用性与许可由提供方决定。
